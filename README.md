# K I S S — Official family website 2.0

Готовый статический сайт игровой семьи K I S S на GTA5RP REDWOOD. Фирменная готическая графика, адаптивный первый экран, интро, плавные появления секций, руководство, рекрутинг, соцсети.

## Структура

- `index.html` — все секции, контент, ссылки, SEO / Open Graph.
- `styles.css` — оформление и брейкпоинты 1200 / 960 / 680 / 380 px.
- `script.js` — интро, скролл-прогресс, мобильное меню, анимации и дата.
- `assets/kiss-cathedral.webp` — авторский готический баннер.
- `assets/kiss-crest.webp` — фирменный герб K I S S, оптимизированный для веба.
- `assets/kiss-crest.png` — оригинальная версия прозрачного герба.
- `assets/og-cover.jpg` — превью 1200×630 для Discord и соцсетей.
- `assets/favicon.svg` — значок вкладки.
- `robots.txt`, `sitemap.xml`, `.nojekyll`, `404.html` — техфайлы хостинга.

## Локальный запуск

Запустите команду `python -m http.server 8000` в папке сайта и откройте `http://localhost:8000`. Прямой просмотр index.html тоже допустим, но локальный сервер ближе к GitHub Pages.

## Публикация GitHub Pages

Репозиторий: `niksogang/kiss-landing-`, ветка `main`, каталог `/(root)`.

1. Загрузите **содержимое** папки в корень репозитория (не папку целиком).
2. В Settings → Pages выберите Deploy from a branch → main → /(root).
3. Адрес сайта: `https://niksogang.github.io/kiss-landing-/` после успешного deploy.

Необходимые файлы картинок должны присутствовать в `/assets/` с **точными** именами; регистр имеет значение.

## Проверено / ограничения

- Меню открывается/закрывается по кнопке и Escape; после перехода закрывается.
- Кнопки и ссылки используют реальные публичные URL, серверных форм нет.
- Интро можно пропустить; в одной вкладке показывается только однажды.
- Поддерживается `prefers-reduced-motion`, интерактивные элементы доступны с клавиатуры.
- Страница не собирает данные и не использует сторонний JavaScript.
- Шрифты загружаются из Google Fonts; при отсутствии доступа применяется системный fallback.
- Сайт — неофициальный игровой фан-проект; не связан с GTA5RP или Rockstar Games.
