# K I S S — официальный лендинг семьи GTA5RP REDWOOD

Публичный адаптивный одностраничный сайт на HTML/CSS/JavaScript. Без сборки, базы данных, API и сторонних JS-зависимостей.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере. Для локальной разработки также можно выполнить `python -m http.server 8000` и открыть http://localhost:8000.
3. Для публикации загрузите **содержимое** папки на Netlify, Cloudflare Pages, GitHub Pages или обычный статический хостинг.

## Что работает

- Адаптивное меню для телефонов, якорная навигация, кнопки вступления и соцсетей.
- Анимации появления секций, бегущая строка, прокрутка и индикатор прогресса.
- Поддержка `prefers-reduced-motion`, клавиатурной навигации, метатеги SEO и Open Graph, favicon.
- Все внешние ссылки открываются в отдельной вкладке.

## Редактирование

- Тексты, ники и ссылки: `index.html`.
- Цвета, шрифты, размеры и эффекты: `styles.css` (переменные `:root`).
- Логика анимаций и меню: `script.js`.
- Изображения, логотип и иконка: `assets/`.

## Важно перед публикацией

- Главный фон и готическая эмблема взяты из предоставленных владельцами семьи материалов. `assets/kiss-banner.webp` — баннер, `assets/kiss-logo-transparent.png` — эмблема с удалённым внешним белым фоном.
- Фотографии персонажей руководства не предоставлены, поэтому карточки используют типографику и инициалы.
- TikTok-ссылка сформирована из указанного `@kiss5rp`; убедитесь, что аккаунт существует.
- Для корректного превью в соцсетях после выбора домена желательно заменить относительный `og:image` на полный HTTPS URL и при необходимости подготовить PNG/JPG 1200×630.
- Google Fonts требует подключения к интернету; при отсутствии соединения используются системные шрифты.
- Контактные ссылки ведут на внешние сервисы. Сайт не собирает персональные данные, не имеет формы с серверной отправкой и не использует cookies/аналитику.
